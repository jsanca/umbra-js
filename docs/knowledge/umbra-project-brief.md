# Umbra Project Brief

Status: Planning baseline — no application implementation exists  
Authority: UMBRA-EXP-001 task brief

Umbra is a didactic ray tracer intended to teach how light becomes pixels by progressing from vectors and rays to camera rays, sphere intersections, normals, lighting, shadows, materials, and Canvas 2D output. The product phrase is: **A small laboratory for learning how light becomes pixels.**

## Sprint 1 product intent

Sprint 1 is a dark, technical, single-page learning laboratory with a central Canvas 2D viewport, restrained render controls, visible resolution/status/render-time metadata, a current-concept panel, and an ordered pipeline. The Stitch dashboard is a product north star; it is not a full UI contract.

## Non-goals

Sprint 1 does not include a scene editor, timeline, node editor, asset library, settings modal, export, real sample control, post-processing, WebGL, Three.js, path tracing, BVH, meshes, textures, Web Workers, external math libraries, or rendering engines.
