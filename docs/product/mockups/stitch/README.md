# Umbra Lab Dashboard — Stitch Mockup

Date: 2026-08-28  
Source: Google Stitch  
Status: Product north star, not Sprint 1 contract

## Purpose

This mockup defines the initial product direction for Umbra: a dark, technical, educational ray tracing lab interface.

It should guide visual language, layout priorities, and the learning/debug experience.

## Sprint 1 Interpretation

In scope:

- Dark application shell
- Header with Umbra identity
- Canvas/render viewport
- Basic render controls
- Scene/debug metadata
- Current concept panel
- Pipeline steps list

Out of scope for Sprint 1:

- Full scene graph editor
- Export frames
- Settings modal
- Complex precision controls
- BVH implementation
- Post-processing
- Advanced material controls

## Notes

The mockup is a design reference and product north star. It is not a pixel-perfect implementation contract.
